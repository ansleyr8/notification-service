# Notification Service

A simple RESTful notification microservice built with **Python, FastAPI, Pydantic, and Docker**.

The service provides APIs for creating and retrieving notifications, validates incoming payloads, generates unique notification IDs, tracks notification status, and exposes health and API documentation endpoints.
